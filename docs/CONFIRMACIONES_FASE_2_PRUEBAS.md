# Confirmaciones · Fase 2 — pruebas

1. Abrir Admin > Confirmaciones.
2. Confirmar que solo aparecen invitaciones que ya tienen una respuesta.
3. Buscar por nombre y código.
4. Filtrar por grupo.
5. Filtrar Asistirá / No asistirá.
6. Filtrar invitaciones activas/inactivas.
7. Cambiar paginación 10/20/50.
8. Abrir detalle:
   - cupo correcto;
   - cantidades confirmadas correctas;
   - mensaje original;
   - fechas en hora de México;
   - historial.
9. Corrección administrativa:
   - cambiar adultos/niños dentro del cupo;
   - motivo obligatorio;
   - mensaje original no cambia;
   - historial agrega origen=administrador, nombre y motivo.
10. Intentar exceder el cupo: debe bloquearse.
11. Actualizar el RSVP público y confirmar que el historial registra origen=invitado.
12. Revisar responsive en iOS y Android.
